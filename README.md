# All About Devin

An offline field guide for engineering and operations teams. Open the **Team Rollout & Quick-Start Map** in the reader to get started. It connects the beginner walkthroughs, the guide to choosing a working mode, the 12 surface guides and the 30 hands-on labs.

[Download the complete book](./All-About-Devin.zip?raw=true). Unzip the download and double-click **Read All About Devin.html** to read offline on a computer. For an iPad, open the GitHub Pages edition in Safari once and wait for **Ready offline**.

The [PowerShell Exchange kit](./practice/exchange-inventory.zip?raw=true) includes sample mailbox data and tests. The kit works locally. Live Devin sessions require an internet connection and access to the service.

See [UPDATING.md](./UPDATING.md) to edit the book, check an edition or rebuild the portable reader and ZIP.
